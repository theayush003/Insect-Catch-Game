# 🪰 Catch The Insect

An interactive, fast-paced browser game where players race against the clock to catch spawning insects before time runs out! Built with vanilla HTML5, CSS3, and JavaScript.

---

## 🎮 Game Features

* **Insect Selection:** Choose your target insect (Fly, Mosquito, Spider, or Roach).
* **Dynamic Gameplay Loop:** Spawns selected insects at randomized coordinates on the screen with random rotations.
* **Increasing Difficulty Curve:** The spawn speed accelerates as your score increases to test your reaction time.
* **Win/Loss Conditions:** Reach a target score of **20** to win within the 60-second time limit, or face a Game Over screen when time expires.
* **Retro Aesthetics:** Styled using Google Font's **Press Start 2P** for an authentic 8-bit arcade feel.
* **Restart Functionality:** Seamlessly start a new game directly from the end-game overlay screen.

---

## 🛠️ Built With

* **HTML5** – Game structure, screens, and element containers.
* **CSS3** – Smooth screen transitions, retro typography, dynamic positioning, and modal animations.
* **JavaScript (ES6+)** – Event listeners, timer management, DOM manipulation, dynamic element generation, and game logic state.
